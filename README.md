# EHCP Outcome Cruncher

A browser-only prototype that turns broad EHCP outcomes or descriptions of need into editable learner-centred outcomes and graduated stepping stones. It includes a generic example bank organised around communication and interaction, cognition and learning, social/emotional/mental health, sensory and physical access, and preparation for adulthood.

The first step offers two clear routes: use and crunch a guided example immediately, or paste an anonymised EHCP outcome. The custom route deterministically extracts the learner action from future-facing outcome wording, suggests a best-fit strand and builds four graduated steps around that action. The strand remains editable within the result.

Optional starting-point, provision and Normal Way of Working (NWW) information is kept in a compact disclosure. NWW flags when the centre's interview/form and access-arrangements process may be needed; it does not approve an examination arrangement.

## Run locally

Serve this folder with any static web server, then open `index.html`. No build step or external service is required.

The prototype stores only the selected colour theme in browser storage. Outcome content is not stored or transmitted.
